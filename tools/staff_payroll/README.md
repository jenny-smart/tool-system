# 內勤薪資管理（staff_payroll）

新增於 `jenny-smart/tool-system`，路徑：`tools/staff_payroll/`

## 根目錄結構

```
根目錄（Drive Folder，1LYmhOIcgjmO5-74zh1D1pKfVizIF5Wls）
└── YYYY薪資
    └── 地區（台北 / 桃園，之後可加新竹、台中）
        ├── YYYY地區薪資單總表（Google Sheet）
        │   ├── 員工個資（工作表）
        │   └── 薪資單（工作表，AA1:AH15 為單人薪資單樣板，AC2 = 姓名）
        ├── 薪資單（資料夾，存放產出的 PDF）
        └── YYYY元大帳戶（Google Sheet）
根目錄
└── YYYY薪資
    └── YYYY內勤薪資名冊（Google Sheet，內含各月 mail 分頁）
```

UI 操作順序：**選擇地區（全部或單一） → 選擇年月 YYYYMM → 選擇功能**

四個功能：內勤結算 / 內勤PDF產出 / 內勤薪資單通知信 / 內勤元大帳戶

### 1. 內勤結算（`settlement.py`）— 已完成

根目錄》YYYY薪資》地區》YYYY地區薪資單總表》薪資單工作表

1. `AC1` 寫入 `YYYY.MM`
2. 清空 `C3:D`
3. 讀「員工個資」工作表 J欄=='Y' 的姓名 → 寫入「薪資單」`B3:B`，對應列 `D3:D` 設為 `TRUE`

### 2. 內勤PDF產出（`pdf_export.py`）— 已完成

- 與清潔承攬/其他承攬的 PDF 產出機制**各自獨立**，互不影響；也跟你截圖裡「D欄勾選→產生PDF」那支既有機制無關，不會重複處理
- 只處理薪資單分頁 `B3:B` 名單裡 **`D` 欄為 `TRUE`** 的人（尊重手動取消勾選，不是整批 `B3:B` 都出），逐一寫入 `AC2`，短暫等待公式重算後，用 Sheets export 端點只匯出 `AA1:AH15` 這個範圍成 PDF
- 檔名：`YYYYMM地區薪資單_姓名.pdf`（如 `202601台北薪資單_賴彥妃.pdf`）
- 存到 `根目錄》YYYY》地區》薪資單` 資料夾，連結寫回「薪資單」`C` 欄對應列：
  - `C` 欄該列原本是空的 → 上傳新檔（同名先丟垃圾桶再上傳，避免疊加），把新連結寫回 `C`
  - `C` 欄該列已經有連結 → 沿用連結對應的原檔案直接覆蓋內容（不新建檔案），重新產出後連結網址不變，之前分享出去的連結還是打得開

### 3. 內勤薪資單通知信（`mail_notify.py`）— 已完成

規格：

```
根目錄》YYYY薪資》YYYY內勤薪資名冊
1. mail工作表A2:Am：YYYY台北薪資單總表》篩選員工個資J欄=Y時，B3:B
2. mail工作表Am+1:An：YYYY桃園薪資單總表》篩選員工個資J欄=Y時，B3:B
3. mail工作表B2:Bm：YYYY台北薪資單總表》篩選員工個資J欄=Y時，F3:F
4. mail工作表Bm+1:Bn：YYYY桃園薪資單總表》篩選員工個資J欄=Y時，F3:F
5. 複製前一個月工作表改成當月YYYYMM，刪除F欄，D欄為YYYYMM
6. YYYY台北薪資單總表》薪資單B3:B及C3:C複製到B2:C
7. YYYY桃園薪資單總表》薪資單B3:B及C3:C複製到B欄非空白列
```

**已確認：**

- ✅ Q1 名單來源：**台北「員工個資 J欄=='Y'」的所有內勤員工 ＋ 桃園「員工個資 J欄=='Y'」的所有內勤員工**（不是看薪資單 D3:D 是否當月發薪，是看員工個資的在職/適用旗標）
- ✅ Q2 步驟5（複製上個月分頁邏輯）：2026-08-19 用實際案例（202607 → 202608）確認 —
  複製「名冊」裡**最近一個月**（不是固定樣板）的分頁 → 改名成當月 YYYYMM → 刪除新分頁的
  F 欄（避免上個月的寄信狀態帶到新月份）→ 把新分頁的 **D1**（不是整個 D 欄）改成當月
  YYYYMM。`ensure_month_tab()` 已依此實作；第一次建立、前一個月分頁還不存在時會丟出
  清楚的錯誤訊息，請先手動建立第一份月份分頁範本。
- ✅ Q3 步驟6、7的「B2:C」：新分頁裡台北資料貼在 B2 開始，桃園緊接在台北最後一列之後，**動態接續、非固定位置**
- ✅ Q4 寄信：這支程式**只整理好名冊/收件清單**，不寄信；寄信是**另一套機制**觸發（跟這支程式無關，不用串 Gmail API）

**實作備註（假設，未對過真實表格）：**

- 規格文字沒有明講「薪資單」F3:F、C3:C 實際存的是什麼，這裡照文字假設 F 欄＝信箱、
  C 欄＝連結；如果實際欄位不是這樣，只要調整 `mail_notify._read_payroll_roster()` 裡
  的欄位索引即可。

### 4. 內勤元大帳戶（`yuanta_account.py`）— 已完成

規格：

```
根目錄》2026》地區》2026元大帳戶
1. 元大工作表E3:E：YYYY地區薪資單總表》薪資單B3:B
2. 元大工作表B3:B：E欄=員工個資B欄 時，對應員工個資C欄
3. 元大工作表C3:C：E欄=員工個資B欄 時，對應員工個資I欄
4. 元大工作表D3:D：E欄=薪資總表D欄 且 A欄=YYYY.MM 時，對應AH欄
5. 另存 YYYYMM元大帳戶-地區.xlsx（存回同一個 Drive 資料夾）
```

**實作備註（照規格文字直接實作，這幾點沒有其他程式碼可以對照，尚未拿真實表格驗證過，
第一次跑請務必先核對輸出結果）：**

- 「元大工作表」規格沒指名分頁名稱，`_get_yuanta_ws()` 目前假設是該試算表的**預設（第一個）工作表**；如果實際上是固定分頁名稱，改這個函式即可。
- 步驟4「薪資總表D欄 且 A欄=YYYY.MM」照字面直接對「薪資單」工作表整份資料的 **A 欄、D 欄、AH 欄**做比對（不是走 AC1/AC2 那組單人樣板的公式重算）；如果薪資單實際上是另外有一份紀錄用的資料表、欄位跟這裡假設的不同，`yuanta_account._payroll_amount_lookup()` 需要對照真實表格調整欄位索引。
- xlsx 匯出用 Drive API 的 `files().export`（不是 Sheets 的 PDF export 端點），已比照 pdf_export.py「同名先丟垃圾桶再上傳」的作法避免疊加。
