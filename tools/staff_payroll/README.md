# 內勤薪資管理（staff_payroll）

新增於 `jenny-smart/tool-system`，路徑：`tools/staff_payroll/`

## 根目錄結構

```
根目錄（Drive Folder，1LYmhOIcgjmO5-74zh1D1pKfVizIF5Wls）
└── YYYY薪資
    └── 地區（台北 / 桃園，之後可加新竹、台中）
        ├── YYYY地區薪資單總表（Google Sheet）
        │   ├── 員工個資（工作表）
        │   └── 薪資單（工作表，AA1:AH15 為單人薪資單樣板，AC2 = 姓名）
        ├── 薪資單（資料夾，存放產出的 PDF）
        └── YYYY元大帳戶（Google Sheet）
根目錄
└── YYYY薪資
    └── YYYY內勤薪資名冊（Google Sheet，內含各月 mail 分頁）
```

UI 操作順序：**選擇地區（全部或單一） → 選擇年月 YYYYMM → 選擇功能**

四個功能：內勤結算 / 內勤PDF產出 / 內勤薪資單通知信 / 內勤元大帳戶
